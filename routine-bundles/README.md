# Optional routine bundles

The `v1/catalog.json` examples are data-only starting points for reading, studying and active screen use. Browse and preview them in Routines, then explicitly add an editable, disabled routine. Missing activities must be downloaded through the activity catalogue before installation. Nothing installs automatically.

See [protocol, contribution and compatibility details](../docs/CONTENT-PROTOCOL.md). Main is the publication branch; obtain maintainer review before merging. Examples do not prescribe health treatment or guarantee improved productivity.
