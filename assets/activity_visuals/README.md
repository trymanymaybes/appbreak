# Activity illustrations

Original decorative illustrations created for AppBreak. Licensed CC-BY-4.0;
attribution: AppBreak project contributors. Reproduce with
`python3 tools/generate_activity_visuals.py` (requires Pillow).

Four GIF loops and matching still PNGs cover quiet/breathing, movement,
hydration and quiz/imagination categories. These are decorative category visuals,
not demonstrations of every activity or prescribed movement/breathing timing.
They are bundled offline. No catalogue-supplied URL or file path is loaded.
Playback is opt-in, can be paused, and uses a still when reduced motion is enabled.
